The Dispatch - News Application
===============================

A publishing workspace built with Django. Editors manage companies and review
stories, journalists write reporting, and readers follow approved content.
Normal use does not require Django Admin or a superuser.

Start with :doc:`installation`, then follow :doc:`usage` to publish your first
article. Developers can inspect the actual Python docstrings in :doc:`reference`.
